# Präsentation & Abgabe

Deliverables des Projekts — getrennt von der Modellarchitektur.

## Struktur

```
Praesentation_Abgabe/
├── Praesentation/          ← Ablageort für die finale Präsentation (wird manuell hochgeladen)
└── Abgabedokumente/
    └── Modellannahmen.docx ← strukturierte Annahmen-Doku (generiert aus MODEL_ASSUMPTIONS.md)
```

## Hinweis zur Quelle der Annahmen

`Modellannahmen.docx` ist eine generierte Word-Fassung — die **fachliche Single Source of Truth**
bleibt [`Modellarchitektur/docs/MODEL_ASSUMPTIONS.md`](../Modellarchitektur/docs/MODEL_ASSUMPTIONS.md)
(wird live im Cockpit-Tab „Validierung → Methodologie" gerendert).
